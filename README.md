# Editorial portfolio starter

A React + Vite editorial-style portfolio template.

## Run locally

1. Install Node.js (LTS version).
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL Vite prints.

## Customize

Edit `src/main.jsx`: update `profile`, `projects`, `articles`, and the About section. Replace all placeholder content with your own writing and actual work. Links left empty display a 'link coming soon' label.

Edit `src/style.css` to change colors, spacing, and typography.

## Deploy

Push the project to GitHub. Import that repository into Vercel, keep the detected Vite framework, set build command `npm run build` and output directory `dist`, and deploy. Vercel provides a public URL. You can also use GitHub Pages with additional Vite base-path configuration.

## Application note

The NYT posting asks candidates not to use GenAI to generate substantive application materials. This is a technical starter template; write all substantive portfolio copy and application materials yourself, and follow the employer's policy.
